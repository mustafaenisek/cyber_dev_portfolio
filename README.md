# Portfolio 🕸️
A modern, responsive portfolio website featuring a dark cyberpunk theme. 

##  Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Styling:** Flexbox, CSS Grid
- **Icons:** FontAwesome
- **Future Stack:** Node.js, React (Planned for V2)

##  Features
-  **Cyberpunk Theme:** Dark mode with neon accents.
-  **Fully Responsive:** Works on desktop and mobile devices.
-  **Animations:** Smooth entrance animations and glitch text effects.
-  **Modular Structure:** Separate `.html`, `.css`, and `.js` files for clean code organization.

##  Getting Started
To view the website locally:
1. Ensure all 3 files (`index.html`, `style.css`, `script.js`) are in the same folder.
2. Open `index.html` in any web browser.

*Note: A simple HTTP server is required for some local features, but standard file opening works fine.*
